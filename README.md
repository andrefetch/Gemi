# Gemi
Gemi is an AI Agent that uses "Gemini 2.5-Flash" as it's trained model for simple tasks that can go from reading and writing files and searching the web to writing python files and assisting with programming in python, this is a free and open sourced project and if you want to contribute please open a PR to do so, below will be a comprehensive guide and relevant information to get this project running for you!
